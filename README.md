# Lucknow Climate & Macro Risk

A plain-English dashboard for family, updated on the 1st and 15th of each month.
Live page: https://comic-jay.github.io/lucknow-risk/

`index.html` is the dashboard (works with JavaScript off, for iPhone/iPad previews).
`rebuild_dashboard.js` re-bakes the static cards after each data update: `node rebuild_dashboard.js index.html`.
General information only, not financial advice or an official forecast.
